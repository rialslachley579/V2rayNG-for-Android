# V2RayNG - Android 网络代理客户端
## 🚀 关于 V2RayNG
V2RayNG 是一款基于 V2Ray Core 的 Android 网络代理工具，支持 VMess、VLESS、Shadowsocks（SS）、Trojan、SOCKS、WireGuard 等多种协议。凭借轻量化设计、强大的路由功能以及稳定的连接性能，V2RayNG 已成为众多 Android 用户常用的代理客户端。
无论是用于隐私保护、网络加速、访问国际互联网，还是作为 Android VPN 替代方案，V2RayNG 都提供了优秀的使用体验。
## 📱 V2RayNG主要功能
支持 VMess / VLESS / Shadowsocks / Trojan / SOCKS / WireGuard
支持订阅链接导入
支持二维码扫描添加节点
内置智能路由规则
支持自定义 DNS 配置
支持 TLS / XTLS / Reality
支持多种传输协议：
WebSocket
gRPC
HTTP/2
TCP
QUIC
流量统计功能
局域网代理共享
分应用代理
深色模式支持
IPv6 支持
